# xiaoming-gzh · 公众号排版 Skill

基于 [isjiamu/gzh-design-skill](https://github.com/isjiamu/gzh-design-skill)（AGPL-3.0）的个人定制版。

**内置主题：蓝橙简约** — 蓝色 `#2563EB` / 橙色 `#D97706` / 暖棕 `#4A3728`，简约克制，留白充沛。

